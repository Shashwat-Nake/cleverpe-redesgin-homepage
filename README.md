---

## ✦ Overview

**CleverPe** (*CleverPe Technologies Private Limited*) is a Bengaluru-based digital affordability and point-of-sale financing platform. This redesign modernizes the brand's digital presence into an award-grade, calm, and trustworthy fintech experience while preserving its genuine credit offerings and regulatory alignment with RBI-registered NBFC lending partners (*Bhanix Finance & Investment Ltd.* and *Respo Financial Capital Pvt. Ltd.*).

---

## 🎨 Visual Design System & Inspiration

The visual language draws inspiration from the architectural elegance of **Vella Bank**, adapted with an original, warm fintech palette:

- **Editorial Typography**: Large, rhythmic headlines in *Plus Jakarta Sans* and *Inter* with tight negative tracking (`-0.035em`) for modern banking authority.
- **Layered Floating UI Composition**: An asymmetrical hero pairing lifestyle photography of a young Indian professional with floating interactive cards (live EMI preview with progress bars, ₹1,50,000 sanctioned credit limit badge, and instant checkout indicators).
- **Light & Restrained Palette**: Calming, high-contrast tones strictly avoiding neon colors, dark navy dominance, or heavy gradients.

## 🚀 Key Features & Homepage Sections

1. **Section 01 – Minimal Navigation**: Sticky glassmorphic bar with CleverPe credit-loop logo, anchor links, partner login, and "Get Started" CTA.
2. **Section 02 – Editorial Hero**: Oversized headline (*"Make life affordable. Pay the clever way."*), layered floating cards, live EMI payment preview, and RBI compliance badges.
3. **Section 03 – Trust & Benefits**: 4 clear digital pillars (Simple digital experience, Flexible payment options, Convenient financing journeys, Transparent information) with outline iconography.
4. **Section 04 – Financing Solutions**: Filterable cards for Buy Now Pay Later (BNPL), No Cost EMI, Electric Vehicle (EV) Financing, Healthcare Financing, and Insurance Premium Financing.
5. **Section 05 – How CleverPe Works**: 3-step horizontal workflow with connecting status lines.
6. **Section 06 – Featured Healthcare Financing**: Editorial split section highlighting desk-side hospital clearance and elective medical coverage.
7. **Section 07 – Electric Vehicle Mobility**: Aspirational green mobility feature highlighting loans up to ₹2,00,000 and 15-minute showroom approval.
8. **Section 08 – Merchant Partnerships**: B2B section highlighting +35% cart conversion, T+1 settlement, and plug-and-play POS/QR integrations.
9. **Section 09 – Interactive EMI Calculator**: Live calculation with sliders for purchase amount (₹5,000 – ₹2,00,000), tenure pills (3–24 months), down payment adjustment, and No Cost vs. Standard mode toggle.
10. **Section 10 – Expandable FAQs**: Accordion covering product eligibility, No Cost EMI mechanics, and merchant onboarding.
11. **Section 11 – Footer**: Full company info, social links, legal policies, and RBI NBFC partner declaration.
12. **Interactive Modals**: Instant digital eligibility checker and merchant partnership lead capture.

## ⚡ Quick Start

### Option A: Direct Browser Preview (Zero Setup)
Simply open the standalone HTML file in any modern web browser:
```bash
# Double-click or open directly in Chrome / Edge / Safari
./preview.html
```

### Option B: Run with Vite Dev Server
```bash
# 1. Clone repository
git clone https://github.com/your-username/cleverpe-redesign.git
cd cleverpe-redesign

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

### Option C: Production Build
```bash
npm run build
npm run preview
```
